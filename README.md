# Venafi / HashiCorp Vault certificate lifecycle lab

Status: implementation plan only. No experiment infrastructure has been deployed.

See [the implementation plan](docs/IMPLEMENTATION_PLAN.md) for architecture, parallel work assignments, runtime acceptance tests, and intended commands. Commands described there are a delivery contract, not yet runnable tooling.

The lab will use the real Venafi Vault PKI plugin with a local HTTPS TPP API simulator and local test CA. It does not demonstrate compatibility with a deployed Venafi TPP instance.
